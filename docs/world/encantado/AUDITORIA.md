# Projeto Encantado — Fase A: referência × jogo (2026-11-21)

Referência: ilustração enviada pelo criador (clareira com raios de sol, fogueira de
acampamento, slime de fogo, slime de água, cachoeira, cogumelos luminosos). É referência de
**qualidade e atmosfera**, não textura a copiar. Capturas reais em `antes_*` (Clareira,
07/09/12/16h30/18h30/22h, 1280×720, GL Compatibility, RX 580; 149–167 FPS, ~470 draw calls).
